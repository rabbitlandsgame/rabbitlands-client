# Rabbit Lands Landfall browser prototype assets

Generated runtime and art payloads for an isolated desktop-browser prototype.
These files are served directly from GitHub; no player database, credentials,
server secrets or private authoring inputs are included.

The source build tool is godot-client/tools/build_web_prototype.py on the
prototype source branch. The payload manifest records that exact source commit
and the length and SHA-256 of every file. All source art came from tracked
Rabbit Lands client content. The game server remains authoritative.

This asset branch is for prototype downloads, separate from develop and master.
Pin its full commit in the small launch site browser-assets.json base_url.
