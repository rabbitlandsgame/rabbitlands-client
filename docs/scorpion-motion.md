# Scorpion motion

Amethyst Scorpion uses the selected seven-action set: idle, raised guard, flinch, alternating-tripod crawl, faster scuttle, overhead sting and supported armored collapse. Its six walking legs, two large pincers, mouth palps and segmented tail keep their distinct roles.

The current imported geometry, textures, original node/joint prefix and rest binds are preserved. An explicit runtime skin preparation assigns each complete rigid section to its anatomical control. This replaces the reviewed dense corrective payload after all-key and between-key surface comparisons. Head and neck attachments use `RL_Scorpion_Head`; body effects use `RL_Scorpion_Body`. The dedicated action map keeps native playback speed and measured ground travel at the unchanged actor scale.

The runtime model is about 4.1 MB, reduced from a 30.4 MB corrective candidate without changing any texture bytes. Every reviewed joint sampler knot is retained; complete-surface deviations from the corrective candidate stay below 0.000017 of native height across all original knots and midpoints. The compact test fixture retains the same numeric witnesses. The import policy requires 4096 FPS, uncompressed meshes, and disabled animation optimization/compression. High-resolution sources, processing stages and review videos remain outside Git.

Run `python eloria-assets/tools/test_scorpion_motion.py` with NumPy and SciPy. After importing the client, run `tests/test_scorpion_motion.gd` in Godot. The checks cover seven slots, independent off-grid bones, morphs, surfaces and normals, complete-piece rigidity, pointed-tip contact, mirrored touchdown advances, support polygons, segment lengths, centered tail, head clearance, floor clearance and separate posterior/middle body support in death. Godot checks also cover the actual scene/library path, loops, held endpoints, action switching and RESET. Sharp tips use point contact rather than flat paw soles. Full game sessions and crowd performance are separate checks.

`eloria-assets/tools/pack_rigid_creature_motion.py` accepts an explicit reviewed source, the public actor profile, an output path and a report path. It rejects changed joint curves or a surface error above the existing 0.00015-height bound. Use this preparation only for models whose entire surface has verified rigid component ownership. Flexible models need their own deformation representation.

Publication and runtime qualification do not create a separate human visual-acceptance receipt for the compact skin representation. Its motion conformance is measured above; further visual review remains available.
