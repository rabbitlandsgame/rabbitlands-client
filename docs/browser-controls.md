# Playing in a desktop browser

Before the first large download, choose **Use browser storage** or **Choose asset
folder**. Folder selection is available in supported desktop browsers, including
Chrome and Edge, when the game is open in its own tab. The game creates a
`RabbitLandsAssets` subfolder and downloads only files it needs. Previously saved
browser downloads are copied there when possible. Damaged files are verified and
repaired; an unavailable folder falls back to browser storage.

The login screen's **Asset storage & shortcut** button reopens these settings.
**Download Windows shortcut** saves a ZIP; extract `Rabbit Lands.url` and open
that shortcut to return with the saved storage choice. It contains a random
reference to the folder permission saved in this browser, rather than a local
path or permission grant. Use the same site and browser profile. The browser may
ask for access again; if site data is cleared or another browser opens the link,
select the existing folder again to reuse its files. The shortcut opens the
default browser and cannot choose its graphics backend.

Connect to the game, then choose **New character** to use the same starting
looks, appearance controls and callings as the desktop client. The connected
server determines which appearance options are available. Cancelling the
starting-look gallery returns to login without creating an account.

Only the selected character has a live 3D preview. Gallery cards use saved
portraits. On a narrow window the gallery hides and pauses that preview; widen
the window to see it again. Entering the world prepares its map after creation,
so browsing looks does not also build a world in the background.

Under **Settings → Graphics**, choose **Fullscreen** to fill the display and
press **Escape** to leave fullscreen. The browser controls frame synchronization
and the rendering backend. Use 3D resolution, graphics quality and the frame
limit to adjust performance.

**Download screenshot** in Graphics saves a PNG through the browser's normal
download interface. The screenshot key also downloads the current screen.
Browser downloads replace the desktop client's screenshots folder.

If game files cannot be downloaded, **Retry** resumes loading and reuses files
already saved on the device. **Settings → Graphics → Retry game downloads**
also retries interrupted character or equipment downloads during play. If files
belong to a different game version, **Reload** fetches the matching launch page.

Browsers reserve some keyboard shortcuts. The game's on-screen controls remain
available, and **Settings → Controls** lets you choose different keys. Keep the
game canvas focused when using game shortcuts; text fields retain their normal
typing and clipboard behavior.
