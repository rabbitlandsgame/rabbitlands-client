# Optional Native cap corrective

`native_cap_fit.fit_cap(native, attributes, triangles, center,
max_extra_triangles, max_shift_mm=14)` accepts only an isolated hidden scalp
shell. It returns refined High attributes/triangles, a separate Native position
delta and an unqualified authoring receipt. Supply every High identity/groom
target in `attributes`; their original rows remain exact and new rows interpolate
the same High surface. The caller owns GLB assembly and the append-only
`append_native_fit` utility.

The optional route picks a coherent outermost radial branch around the Native
ear crease, refines only measured deep-contact faces within a strict budget,
then checks vertices and the existing 5 mm triangle-interior probes. It fails
closed if the final total displacement exceeds its bound or clearance is below
2 mm. Generic default displacement stays 14 mm. A different style-local bound
must be explicit, recorded and reviewed; this is not runtime registration or
asset acceptance. Painted exterior, backing, actual Native controls/poses,
High identities, grooming, scalp coverage and LOD budgets remain separate gates.

`radial_stand_off_mm=2.3` and `vertex_margin_mm=2.2` preserve the initial
defaults. A caller can explicitly increase the stand-off within the same total
motion bound to trade vertex clearance for fewer required adaptive faces. The
receipt records both values; the final 2 mm gate and triangle budget still apply.
