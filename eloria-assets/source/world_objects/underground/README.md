# Reused underground scenery

Run `python tools/prepare_underground_scenery.py` from the client checkout to package the 32 selected imported models and the 218 interior placements. The Cenote Deeps (owner, 2026-10-20) adds 23 pieces of Landfall A3's `lf-biomes` jungle kit: limestone crags and boulders for its walls, the waterfall, jade shrines and lanterns, a serpent brazier, serpent ruins (the arch over its way out and over Coilmere's door, an altar, a pillar, an obelisk, a frieze), lotus pads, reeds, ferns, undergrowth, a geode, toadstools and a log. Its placements come from `build_underground.dressing()`, the list the walk grid is cut from; its crystals reuse the cluster in a jade palette. `reused-scenery.json` binds the current sources, textures, output files and bounds to SHA-256 hashes. No retired procedural model is restored.

The cave mouth is the preserved Meshy asset from `whitehorn-ice-cave-mouth-v001`, task `01a0b927-06cb-725a-9639-ac8a2091b1aa`. Its current normalized, external-texture GLB is pinned by hash in the processor. The historical adapter describes the original source and has a different frozen hash; its receipt is not rewritten. This runtime object packaging does not activate the old regional adapter.

The processor expands the cave's quantized attributes to equivalent float arrays (error below 0.0000001 native units) for the editor's importer. The original binary payload stays intact. Runtime and standalone editor import both accept the packaged result.

`cave-earth-basecolor-v001.png` was generated by editing the existing Meshy base-color atlas (`8d51cf70456b91bfb08a623c10b8ccb8f82b9348926331dd1bbfb70f11c3722a.jpg`). The exact edit prompt is in `cave-atlas-prompt.txt`. The normalized UV layout is retained; snow and ice become matte earth and stone. Original ORM and normal images are preserved in the GLB, with metallic-roughness sampling disabled and the normal strength reduced. The passage floor sets the vertical placement, rather than the lowest outer stones.

Lanterns reuse only the original head and bracket faces, avoiding tall posts floating beside cutaway walls. Rails are thin floor dressing. Crystal clusters occupy the former blocked patches. The map's existing floor, walls, collision and routes are retained; these are presentation assets. Runtime application is idempotent and also applies when an older map cache is loaded.

The three imported veined-boulder forms also replace retired mineral placeholders. Runtime material palettes retain the source texture's painted values and facets while recolouring its vein pigment for Coal, Iron Ore, Copper, Sulfur, Slate and Geode. Crystal uses the existing cluster. These shader variants do not edit a raster image or restore a retired model. Each retains its server resource name; the harvesting ring appears only during active gathering. Quartz and Salt stand the approved seam and pan patch models (`quartz_seam_a/b`, `salt_pan_a/b`). Those do not stand alone at a random yaw, and the underground package states no harvest presentation, so the processor writes each node's variant and yaw into `underground-scenery.json` (`harvestPresentation`, from its `HARVEST_PRESENTATION`). The values reproduce the art reviewed on October 19.

The native underground integration check renders all four exterior entrances and the four room types. The reviewed October 19 captures are retained in the ignored local authoring/QA workspace. An unused timber-entrance concept remains in the private authoring stage. No new Meshy generation or upload was needed or submitted.
