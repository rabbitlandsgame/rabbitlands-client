# Quaternius source assets

The luminous male and female source meshes are derived from the free Standard
edition of **Universal Base Characters** by Quaternius. The luminous player
animation source is derived from the **Universal Animation Library** by
Quaternius. The buzzed, simple-parted, long, and buns hairstyle sources are
also taken from the Standard Universal Base Characters pack; their copied
reference textures are reduced to the 512-pixel resolution embedded by the
runtime asset builder.

The Glasswarden ship on a second, slimmer base body. It is not a new source
mesh: it is the same Standard Universal Base Characters geometry, with the same
topology, UVs and skin weights, re-proportioned by the radial field in
`BASE_BODIES` in `eloria-assets/tools/build_native_nymara_glbs.py`. It is a
derivative of the CC0 original and carries no other provenance.
