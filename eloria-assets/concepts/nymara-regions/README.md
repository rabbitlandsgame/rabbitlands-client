# Nymara regional map concepts

These original CC-BY-4.0 paintings are the authoritative composition references
for the generated Nymara exterior maps.  They were derived from
`nymara_continent_master_concept.png` for the Eloria project and contain no
Eternal Lands artwork.

The runtime generator converts each exterior concept to a 512x512 uncompressed
RGBA DDS with four mip levels.  The PNGs are also editable production inputs for
terrain, architecture, vegetation, lighting, and map-layout refinement.

The paintings are not collision maps.  Gameplay coordinates and traversal are
defined by the region packages under `maps/nymara-regions/` and the
authoritative server profile.
