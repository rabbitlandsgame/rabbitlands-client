# Mirrorhold production map

A 384 m x 384 m Nymara region: an observatory citadel on a mountain summit,
crowned by a mirror-sphere in a brass armillary; a civic descent of terraces,
canals and switchback roads down its south face; and a glacier-fed lake in the
southern basin with a colonnaded ring at its centre on four causeways.

Everything in this package - every mesh, every texel - is generated by the code
in `source/` and the shared toolkit in `../_toolkit/`. Nothing is imported.

## Contents

| File | What it is |
| --- | --- |
| `world.glb` | Self-contained glTF 2.0. Geometry, materials and embedded textures. No extensions, no external files. |
| `world-lod2.glb` | Reduced package: far-tier vegetation only, no ground clutter, half-resolution textures. Not selected by the loader; it is there for low-end machines. |
| `world.json` | The runtime manifest: bounds, coordinate transform, spawns, collision, navigation, landmarks, interactives, markers, harvestables, portals, roads, water, environment, minimap transform, provenance. |
| `collision.bin` | 768 x 768 half-metre traversability grid, `EWCG-v1`. |
| `minimap.webp` | Rendered from the final geometry, not drawn. |
| `references/` | Concept art, captures and comparison sheets. |
| `source/` | The region: composition, placement passes, built kit, camera set, build script. |

## Building it

```sh
make -C ../_toolkit/native            # preview rasteriser; not needed for the package
cd source
python3 build_mirrorhold.py           # world.glb, world.json, collision.bin, minimap, LOD2
python3 ../../_toolkit/verify_runtime.py --package ..
python3 ../../_toolkit/validate_gltf.py ../world.glb

# the same grounding contract in-engine, through the real WorldLoader
cd ../../../../godot-client
Godot --path . --headless \n  --script ../eloria-assets/maps/nymara-regions/_toolkit/region_client_check.gd \n  -- --manifest=<abs>/mirrorhold/world.json
python3 ../../_toolkit/export_server_collision.py    # regenerates ../server-collision/mirrorhold.bin
python3 ../../_toolkit/capture_views.py        # offline preview captures
python3 ../../_toolkit/make_comparison.py      # concept-versus-build sheets
```

The build is deterministic: a cache-cold rebuild reproduces every artefact
byte-for-byte. Runtime startup never depends on rerunning any of it.

## Interiors

Three, authored on the shared interiors toolkit and documented in
`../interiors/MIRRORHOLD_INTERIORS.md`:

All three share one map, `mirrorhold_interiors` - separate blocks on a 204 m
square with unreachable ground between them, in the Eternal Lands manner.

| block | name | entered from |
| --- | --- | --- |
| `lens-vault` | The Lens Vault | the orrery drum |
| `cistern` | The Mirror Cistern | the fountain plaza |
| `cellars` | The Stair Cellars | the cliff town |

```sh
cd source && python3 build_interiors.py
```

Passes the in-engine check with zero walkable cells lacking a surface. The
server map and its three portal pairs are on
`feature/mirrorhold-576m-server-map`.

## Server dependency

This package requires a 64 x 64 ELM map (384 one-metre server cells), server
origin `(120, 96)`, and default arrival `(93, 82)`. Integration synchronises the
registry, collision grid, content and portal contracts together. The coordinate
migration is revision guarded; repeat builds do not compress content twice.

## Editor kit

`source/prepare_meshy_kit.py --input <mirrorhold models> <verdant models>` seats the
generated models in the territory palette's kit
(`godot-client/world_authoring/regions/mirrorhold/assets/prototypes/kit-*.glb`):
the Mirrorhold set from `work-output/mirrorhold-2026-09-27/asset-prompts.md`
(alpine firs and pines, juniper, flower cushions and tussocks, snow-capped
boulders and scree, sun mirrors, lens stands, telescopes, a mirror obelisk,
lens-grinder bench, lens crates and sign, sundial, planters, benches, potted
cypress, a market stall, banner poles, a drinking fountain, glassware cart,
laundry line, a stone landing stage, rowing boat, mooring posts and a heron
weathervane) and the Verdant Stair models this bowl shares (mossy crags and
boulders, saplings, meadow flowers, flowering shrubs, reeds), each taken from the
first folder that has it. Each is scaled to its size in `SIZES`, stood on the
origin, and its textures shrunk and content-addressed into `assets/textures/`;
`source/prepare-meshy-kit.json` records the input and output digests and `--check`
verifies them.
