# The Resin Road — layout coverage

| Space | Purpose and navigation cue |
| --- | --- |
| Staging | Supply bay, cart and stacked timber; clear centre and obvious home stone |
| Undercut | Braced cart road with side storage; roots first intrude around the exit |
| Root Cellar | Resin collection vats at one bank, with a large root arch framing the onward door |
| Sap Bridge | Railed stone span over dark water, taller lamp posts and enclosing roots |
| Stump Stair | Three-metre incline ends at a haul winch and cart landing |
| Twin Hollows hub | Visible wet collection basin and dry timber stack advertise the branch choice |
| Wet Hollow | Stone-lined seep basin and living root arch |
| Dry Hollow | Packed-earth storage hall, stacked timber, braced frames and winch |
| Merge | Barrel transfer bay and lamps lead back to the main route |
| Lantern Walk | Frames at ten-metre intervals; lit resin alcoves and the retained Toadstool bay |
| Boar Court | Large root crown frames the raised boss floor; lateral roots bound the fight |
| Vault | Stored barrels, reward cache and home waystone |

The server's two bands and three instance copies retain their published enemies,
counts, variants, rewards, keeper and exterior return berth. Only positions and
room bounds change. All nine gate approaches and their destinations are walkable;
each legal leg-to-leg route, both fork branches, the boss and vault are connected.

There are 3,900 authored walkable server tiles. Every one has a rendered Walk
surface beneath its centre. The void between rooms and the sealed gate cuts are
intentional non-walkable space.
