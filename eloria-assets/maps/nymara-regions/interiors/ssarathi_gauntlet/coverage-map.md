Both published bands and all three instance copies preserve creature types,
counts, variants, rules, rewards, the keeper and exterior return berth.
The existing Lichen node keeps its name and object identity. Only content
coordinates, bounds and collision follow the new layout.

The gauntlet tests check every gate approach and destination, legal routes
between legs, both branches, the boss and the vault. An independent check
casts beneath every walkable server tile onto the exported GLB.
Final counts and hashes are recorded in references/validation.json.

The final grid has 3,686 walkable server tiles, all backed by exported ground.
