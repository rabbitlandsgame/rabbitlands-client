# Grey Moor Barrows concept package

The ten-panel brief for the barrows under the Grey Moors. **Built**: the
geometry lives at `../grey_moors_insides/`, four barrows on one map with
blackspace between them, and the convention and grading are written up in
`../GREY_MOOR_BARROWS_INTERIORS.md`.

`references/00-concept-detail-board.png` was the truncated 786,445-byte copy
described in section 3 of the region production guide - only the top row of
five panels decoded, and unlike the region's board its zlib stream yielded no
rows at all. The intact 2,726,489-byte board was found in `maps_concept_art/`
and is now the tracked file.
