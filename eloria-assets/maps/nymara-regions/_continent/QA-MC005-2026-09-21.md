# MC005 decorative cliff-house sill QA

Status: validated isolated build. Owner deployment and live confirmation remain
pending.

## Change

MC005 changes only `mirrorhold/source/landmarks.py` and its focused test. The
existing house body, roof, windows, jetty, railing, placements, terrain, and
walk parts remain unchanged. Each of the 27 production cliff houses gains one
closed, positive-volume timber sill directly beneath the existing decorative
railing. It overlaps the jetty and railing physically, remains inside the
existing roof bounds, and is intentionally non-walkable.
