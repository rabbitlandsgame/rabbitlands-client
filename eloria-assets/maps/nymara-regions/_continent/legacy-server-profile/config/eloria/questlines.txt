# Eloria region quest lines. Read by eloria/questlines.py.
#
# A [quest] block is one named chain. Its [stage] blocks run in file order and
# a stage is closed by taking it back to the person it names. When every stage
# is closed the player returns to the quest's `start` for the large reward.
#
# Fields on [quest]:
#   key           the state key; never change one that has shipped
#   id            the number HERE_IS_QUEST_ID sends; never reuse one
#   tier          1-4, and the tier is a promise about the reward (see below)
#   title         what the journal calls it
#   region        where it mostly happens, for the journal's location column
#   start         the NPC who offers it and pays it out
#   requires      comma-separated keys of lines that must be finished first
#   min_level     overall level before the line is offered at all
#   summary       one line, shown when the quest is offered
#   offer         what the start NPC says when offering
#   accepted      what they say when the player takes it
#   complete      what they say when they pay it out
#   repeat        what they say afterwards, forever
#   reward_xp     skill=amount, comma separated
#   reward_gold   coins
#   reward_items  Item Name=count, comma separated
#
# Fields on [stage]:
#   kind          talk | kill | harvest | deliver | visit | mix | read
#   npc           who closes the stage (blank means the quest's start NPC)
#   target        creature type id, resource name, item name, or book title
#   amount        how many (default 1)
#   map, x, y     where; a visit needs all three, a harvest may name a patch
#   objective     the journal line
#   prompt        what the stage's NPC says while it is outstanding
#   done          what they say as they close it
#   xp/gold/items the small reward for closing this stage
#
# ---------------------------------------------------------------------------
# REWARD SCALING
#
# The tier decides the size of the whole line, stage rewards included. These
# bands are checked by tests/test_questlines.py, so a line that pays outside
# its tier fails the build rather than quietly becoming the best quest in the
# game. They are set against the Eternal Lands quest tables the profile is
# modelled on: an errand pays like Granny Lorpak's, a regional chain like
# Clogged Sewers, and a cross-region epic like the Lost Axe.
#
#   tier 1   errand, 2-3 stages      1,500 -   4,000 total xp,    150 -    600 gc
#   tier 2   regional, 3-4 stages    8,000 -  20,000 total xp,    600 -  2,500 gc
#   tier 3   chain, 5-6 stages      28,000 -  70,000 total xp,  2,000 -  7,000 gc
#   tier 4   epic, 7+ stages       110,000 - 220,000 total xp, 10,000 - 30,000 gc
#
# Within a line, stages pay roughly a tenth each and the finish pays the rest,
# so abandoning a line most of the way through costs the player most of it.
# ---------------------------------------------------------------------------
