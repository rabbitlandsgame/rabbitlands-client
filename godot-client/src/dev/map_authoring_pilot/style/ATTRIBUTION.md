# Map authoring pilot texture attribution

The 36 `textures/*.png` files are byte-for-byte copies of the twelve Sunmane
Steppe PBR texture triplets from
`eloria-assets/maps/nymara-regions/sunmane_steppe/textures/` (ground, timber,
stone, thatch, textile, canvas, metal, leather, hide, bone, crystal and cavern).

They are original Eloria project work licensed under CC-BY-4.0. The copies are
kept beside the pilot because Godot imports resources from inside `res://`.
