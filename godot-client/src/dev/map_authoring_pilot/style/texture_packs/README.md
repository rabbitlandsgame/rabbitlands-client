# Region texture pack

Ten square, painterly albedo sources for ground and architectural materials. The textures are candidates for the listed regions; assignment to a scene or material remains a separate review.

| Texture | Suggested use | Repeat scale | Candidate regions |
|---|---|---:|---|
| alpine-scree-lichen | ground | 4 m |  |
| alpine-snow-crust | soft pale bluish-white snow crust with low-contrast granules and sparse fine rock dust | 4 m | Whitehorn Range, Mirrorhold |
| coastal-limestone-gravel | ground | 4 m |  |
| delta-silt | ground | 4 m |  |
| forest-floor-moss | ground | 4 m |  |
| jade-masonry | architecture | 2 m |  |
| marine-timber | weathered exterior timber planks for piers, boardwalks, and coastal structures | 2 m | Westhaven, Crownwater, Manymouth Delta |
| moor-peat-heather | ground | 4 m |  |
| reed-thatch | bundled reed-thatch roof surface | 2 m | Sunmane, Manymouth Delta, Westhaven |
| weathered-limestone-masonry | architecture | 2 m |  |

Each asset folder contains its PNG and a manifest with the exact generation prompt, source hash, design-reference hashes, repeat intent, and suggested roughness. Design references were not supplied as image-generation inputs. The snow folder preserves v001 provenance and selects v002 after reducing visible edge darkening.

Only albedo/base-color art was generated. No normal or ORM artwork is included. Existing detail maps may be reused only after confirming their scale and surface compatibility; otherwise use a reviewed scalar roughness setting.

See tile-review.html for the CSS repeated-tile review sheet. Browser rendering was unavailable in the generation session, so visual acceptance of axis continuity remains pending the coordinated repeated-plane capture.
