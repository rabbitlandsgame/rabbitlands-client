# Jukebox menu icon

`jukebox.png` was generated for Rabbit Lands on 2026-10-31 using the live
leaderboard, exchange and mounts menu icons as references. Its gold lyre and
ivory musical note share the existing dark teal inset and clipped brass frame.
The original generated raster is retained here; the HUD sizes it with the other
menu buttons, using mipmaps to keep the larger painting readable at HUD size.

The exact prompt, source references, generation metadata and review receipt are
kept in the ignored local asset-authoring workspace.
