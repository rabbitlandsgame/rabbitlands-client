# Rabbit Lands creature animation

After creature motion is complete, use the [creature runtime optimization skill](../rabbitlands-creature-runtime-optimization/SKILL.md) for delivery candidates with at most 30 samples/second, offline mesh/skin corrective reduction and ordinary uncompressed GLBs. Preserve dense authoring evidence, qualify sampling and rebaking separately in the actual client, compare reduced-basis controls, and retain measured residual corrections/helpers where needed. Acceptance remains actor-specific.



For a canine continuation, read `docs/creature-video-motion.md` and `eloria-assets/source/animations/canine/manifest.json` before selecting a fit. Seven reviewed canine profiles, prepared inputs and native curves are packaged there. Their replay command is offline; it does not infer anatomy for a new actor. Use `eloria-assets/tools/video_motion` for native fitting, surface/contact evaluation, temporal regularization and physical chain diagnostics.



Read [the motion audit](references/motion-audit.md) for the lessons behind the selected fits. Keep source evidence, fitting assumptions, skin repairs, numerical qualification and visual acceptance distinct. A generated video is a reference, not a skeleton export. A paid provider job or non-public upload needs its own scoped user authorization; do not generate another video to recover local work.



Preserve stable IDs, textures, binds and unrelated accepted actions. Requested skin/rest defects become explicit versioned prepared inputs. Before runtime promotion compare against the current Rabbit Lands assets, whose unrelated clips can be newer than the pilot baseline. Preserve their world-space transforms through rig repairs and neutralize new controls. `video_motion.promotion` requires an unchanged original node prefix and rest-world correspondence; it is not cross-anatomy retargeting.



Use lossless packing before considering approximate optimization. `video_motion.packing` removes unreachable storage and exactly constant interior keys while retaining clip duration. Verify all static arrays and fitted channel values, including both influence sets. Unknown binary extensions require explicit support. Skin joint accessors must remain unsigned integer VEC4 values; the float-only animation helper `video_motion.packing.append_array` is not suitable for JOINTS data. Validate accessor component types before native numerical checks, since a reader that casts indices can hide invalid glTF storage. Geometry-only duplicate pruning can erase valid animation changes.



Persist import fidelity settings and measured walk speed at the actual model scale. Opted-in canine maps account for runtime small-creature and server scaling. Godot's glTF bake cadence is separate from optimizer/compression settings: declare the required cadence in asset metadata, track the matching importer FPS and honor it in both raw scene/library paths. Compare engine world poses to independent GLB witnesses off the bake grid; two engine imports can agree while both lose fidelity. Test loops, held endpoints, action switching, RESET and actual eight-influence meshes. Validate exported keys and between-key poses, portable replay and full-cadence multi-angle review. Keep reports bound to the exact final combined file.



Public changes belong only in the current Rabbit Lands repositories. Keep private authoring paths, provider receipts, credentials and migration records outside Git. Follow root repository instructions for branch policy and repository-scoped identity. Update the manifest and evidence whenever a dependency or selected output changes.
